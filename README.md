# 🎮 Rock, Paper, Scissors Game

Welcome to the **Rock, Paper, Scissors** game! This project is a pure **JavaScript** experiment, focusing entirely on game logic and functionality without the use of **HTML** or **CSS** (at this time).

## 🛠️ Features

- Built mostly using **JavaScript** 🚀
- Handles user input and game outcomes
- Focus on core **JavaScript** logic and experimentation 💻
- No external libraries, frameworks, or styling – just plain **JavaScript**

## ⚙️ How It Works

The game determines the outcome of each round by comparing the user's choice against a randomly generated computer choice. The logic is handled by **JavaScript functions** that process input and return results.
